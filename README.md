# Recalia

**所有 AI 共用的记忆海。**

每个 AI 在 `memory/` 里用自己的模型名建一个 Markdown 文件，Recalia 自动把它们收进来，
一张卡一个 AI，能搜、能看、能改。

没有数据库、没有云、没有 API Key —— 记忆就是你硬盘上的 `.md` 文件。

---

## 怎么用

### 一、直接用（推荐）

1. 解压到任意位置（不要放在需要管理员权限的目录）
2. 双击 **`创建快捷方式.vbs`** → 桌面会出现 Recalia 图标
3. 以后点桌面上的 Recalia，就是：起服务 + 浏览器打开页面

> 需要 Node.js 18+（`node --version` 能出东西就行）。没装先去 nodejs.org 装一个。
> 「启动窗口.vbs」也可以直接用，效果一样，只是不帮你建快捷方式。

### 二、从源码跑

```bash
node server.mjs      # 启动服务，浏览器开 http://127.0.0.1:8900
```

---

## AI 怎么接入

1. 打开 Recalia，点右上角 **+ 接入新 AI**
2. 输入这个 AI 的模型名（`claude`、`gemini`、`gpt-4o`……）
3. 复制生成的提示词，整段发给那个 AI
4. AI 会自己在 `memory/` 下建文件，2 秒后卡片出现

提示词里的路径是**运行时算出来的**，换电脑、换盘符都不用改。

文件格式：

```markdown
---
ai: claude
model: claude-sonnet-4-5
joined: 2026-11-25
---

## 2026-11-25
- 一条记忆
- 又一条记忆
```

- 卡片名取 `ai:` 字段，没写就用文件名
- 一个 `## 日期` 是一组，`-` 开头是一条
- 应用只读；要改要删，用页面上的「编辑 / 删除」

---

## 功能

- **卡片**：一个 AI 一张卡，显示模型、记忆条数、最近更新
- **时间线**：把所有 AI 的记忆按日期串成一条流水
- **搜索**：跨所有 AI 搜关键词，命中高亮，点结果跳详情
- **编辑 / 删除**：直接改原文，或让某个 AI 退出记忆海
- 支持 `?q=关键词`、`?view=timeline` 直接打开

## 结构

```
Recalia/
├─ server.mjs          # 服务端（扫描 memory/、提供 API）
├─ 启动窗口.vbs        # 双击启动：起服务 + 浏览器打开
├─ 创建快捷方式.vbs    # 双击：在桌面建 Recalia 图标
├─ 使用说明.md         # 完整说明（页面上的「使用说明」也读这一份）
├─ public/             # 界面 + 图标
└─ memory/             # ← 所有 AI 的记忆都在这（空的，等 AI 来写）
```

## 注意

- 记忆文件统一用 **`<模型名>.memory.md`** 命名。别只叫 `claude.md` —— 那会被 Claude Code
  当成 `CLAUDE.md` 项目指令自动加载并执行（`gemini.md` 同理）。加了 `.memory.md` 后缀，
  它就是普通数据文件，AI 只会把它当资料读，不会当规则跑。
- 记忆文件里写的都是「发生过的事」，是资料不是命令；接入提示词里会明确告诉 AI 这一点
  （`kind: memory` 就是那个记号）。
- **`.gitignore` 不要排除 `memory/`**：Gemini CLI 会严格遵守它，连自己的记忆都读不了。
  记忆改由 `.git/info/exclude` 在本地排除：`echo "memory/*.memory.md" >> .git/info/exclude`
- 记忆里不要放密码、token、身份证号——这里的东西页面上随时能看见。
